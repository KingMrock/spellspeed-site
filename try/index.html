Import / Export

Take this deck to DuelingBook

In DuelingBook's deck constructor, click Import, choose YDKe Code and paste the code, then save the deck. The .ydk file works too: Import → YDK or XML file.

Bring a deck in

Paste a YDKe code (in DuelingBook: Export → YDK Code) or the text of a .ydk file, or open a .ydk file. It replaces the deck here.

Card search, Access, Starters and the Summon Lab read the card texts; they are not rules-complete. Your deck stays in this browser. In DuelingBook, Spellspeed adds the same search to the real deck constructor, with drag and drop, saving and Solo testing.
